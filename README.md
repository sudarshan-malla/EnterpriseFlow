
# EnterpriseFlow — HR & Workflow Management System

An enterprise-style web application for employee management
and leave approval workflows.

## Features
- Employee record management
- Leave request submission and review
- Leave balance validation
- Audit logging
- RESTful API endpoints

## Technology Stack
- C#
- ASP.NET Core Web API
- Entity Framework Core
- SQLite
- HTML, CSS, JavaScript

## Prerequisites
- .NET 8 SDK
- Git

## Run Locally

```bash
git clone YOUR_REPOSITORY_URL
cd EnterpriseFlow
dotnet restore
dotnet build
dotnet run
```

Open the localhost URL printed by the application.
